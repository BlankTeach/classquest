# ClassQuest outcomes

- [x] **Student access and responsive classroom UI** — Students enter their name or select a class student without a password and choose a game. Simple clear English labels. Fully responsive for interactive whiteboards in landscape and iPad portrait/landscape; large touch-friendly buttons and colorful classroom-friendly design.
- [x] **Grammar and vocabulary quiz** — One question at a time, 3–4 large answer buttons. Grammar content covers all specified tenses, imperatives, indirect speech, passive, phrasal verbs, infinitives, modals, nouns, quantifiers, pronouns, demonstratives, there is/are, possessives, comparison, connectives, determiners, prepositions, gerunds and adverbs. Vocabulary based on definitions/categories across textbook 1A–6B and all supplied topic groups.
- [x] **Category Sort** — 6–8 vocabulary words and 2–3 labeled baskets; 10–15 prebuilt levels based on supplied vocabulary; mouse and iPad touch drag-and-drop plus tap accessibility.
- [x] **Memory Match** — 4x4 or 4x5 face-down grid; match words and definitions, pictures or translations; 10–15 prebuilt levels using supplied vocabulary; large easy-to-tap cards for whiteboards and iPad.
- [x] **Scoring and results** — All correct +5; some correct but not full +3; 1 or 0 correct +1. Results show score and points earned; immediately update billboard. Persist game results and avoid duplicated awards.
- [x] **Teacher access and management** — Dedicated Teacher Login with password 87654321 only. Teacher sees all students and current points, adds/removes students, can reset game scores or clear leaderboard. Every +/− action opens a popup requiring a reason, saved in a timestamped log.
- [x] **History and billboard** — Full point history includes game scores and manual adjustments with reasons and timestamp. All students ranked highest to lowest, top 3 highlighted gold/silver/bronze; visible to signed-in students; updates automatically across devices.
- [x] **Persistent data** — Managed database saves students, points, game results and logs across refreshes and sessions. If local-only fallback were used, display exactly: Points are saved on this device only. For cross-device sync, a backend database is required. No silent local fallback planned.
- [ ] **Delivery** — Runtime ready, route manifest accurate, diagnostics and existing checks clean, read-only integration review completed, project logo URL set, checkpoint recorded.

## Curriculum and variety update

- [x] **PDF curriculum** — Exact vocabulary from merged.pdf pages 5–18 organized by 1A–6B/chapter/category, grammar/tenses aligned with chapter emphasis on pages 1–4, source page metadata, level/chapter selection and a readable curriculum browser. Existing history and points remain unchanged.

- [x] **Sentence Builder and Fix the Sentence** — Scrambled words/chunks draggable and tappable into order. Fix the Sentence lets a student tap the incorrect word and type its replacement; optional timed five-sentence speed round for iPad.
- [x] **Preposition Maze and Story Builder** — Visible grid maze, correct preposition choices advance character and wrong answers block progress. Scenario-based story choices combine vocabulary/grammar and add a sentence for each correct choice; solo or whole-class voting.
- [x] **Who Am I and Charades** — Clue-based word guessing with yes/no narrowing prompts; teacher-moderated whiteboard charades hides/reveals an action for the performer, class guesses, teacher confirms correct guesses.
